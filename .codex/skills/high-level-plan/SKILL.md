---
name: Logic Plan Skill
description: Generates high-level implementation plans with modules, methods, and logical flow.
trigger: generate plan
---

When the user requests a plan, analyze the described feature. Break it down into modules, list the main methods of each module, and describe the logical flow: which methods are called and in what order. 
Do not provide code details. The plan should show the logic, the sequence of steps, and the responsibilities of the modules. 
Ensure the plan reflects the feature, is clear, and can be approved before moving on to code.
